# 3.2.0 文字生成语音

机器人 DT202600001，工作空间 ~/voice_1_ws。MQTT 账号配置沿用包内文件。

默认取消桥接 HTTP 请求超时和发布工具等待回执超时。http_timeout: 0 表示无限等待；
发布工具 --timeout 0 表示无限等待。MQTT 心跳及自动播报间隔保留。
操作系统、网络或机器人服务仍可能自行断开连接；接口一直不返回时不能产生最终执行结果。

中台向 thing/robot/DT202600001/services 发布 JSON，订阅
thing/robot/DT202600001/services_reply 获取回执。每次新操作使用唯一 tid。

```json
{"tid":"unique-request-id","method":"voice_package_update","timestamp":1789354628341,"data":{"robotCode":"DT202600001","voices":[{"name":"左转.wav","text":"请注意，机器人左转","type":"Chinese"}]}}
```

同名文件始终覆盖（overwrite 字段不再控制跳过）：先删除再生成，随后查询列表确认存在。
这是非原子操作：生成失败时旧同名语音已删除。三个固件保护文件不能覆盖。
批量请求失败前已完成的文件不会回滚。不会删除不相关的旧英文名称文件。

默认名称及 MQTT 状态播报对应：正在巡检中请勿靠近.wav、机器人停车请避让.wav、
倒车请注意.wav、左转.wav、右转.wav、机器人避障中.wav。
独立 HTTP 安装/监测工具仍使用包内原英文名 WAV；日常使用 MQTT 启动文件。

```bash
roslaunch robot_voice_announcer mqtt_voice_bridge.launch
# 另一个已加载 voice_1_ws 环境的终端
rosrun robot_voice_announcer publish_voice_package.py --update
rosrun robot_voice_announcer publish_voice_package.py --list
rosrun robot_voice_announcer publish_voice_package.py --play '左转.wav'
```

所有支持的中台指令（更新、列表、播放）最终回执均包含 data.result：0 成功，1 失败，
message 给出原因；机器人终端打印完整回执。发布工具还打印 stage=publish 的本地发送
提交结果，它不表示机器人已完成。必须以相同 tid 的 services_reply 为最终执行结果。
中台前端需要由中台开发人员读取 data.result 并显示，本包无法更改中台网页。
启动桥接不会主动生成语音，仍需下发更新命令。
